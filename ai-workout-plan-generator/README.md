# AI Workout Plan Generator 🏋️

A Streamlit web app that generates a personalized weekly workout plan using an LLM via the Groq API. Fill in your personal details and workout preferences, and the app builds a structured prompt and returns a day-by-day plan — exercises, sets, reps, rest times, warm-ups, cool-downs, and progression guidance.

## Features

- **Multi-input Streamlit form** — personal info (name, age, gender, height, weight) plus workout preferences (goal, experience level, days per week, location, equipment, activity level, duration, style, preferred days, injuries/limitations)
- **Input validation** — required-field checks, a consent checkbox, and a check that the selected preferred days match the days-per-week slider
- **Structured prompt engineering** — the LLM is instructed to personalize every recommendation (no generic plans), respect the user's equipment, location, and duration constraints, avoid exercises that conflict with injuries, and include rest, recovery, and progression guidance
- **Groq API integration** — generates the plan with an LLM and renders it as Markdown directly in the app

## Tech Stack

- Python
- Streamlit
- Groq API (`groq` Python SDK)
- python-dotenv

## Setup

1. Clone the repo and enter the project folder:

   ```bash
   cd ai-workout-plan-generator
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file with your Groq API key:

   ```
   GROQ_API_KEY=your_key_here
   ```

   You can get a free key at https://console.groq.com

4. Run the app:

   ```bash
   streamlit run app.py
   ```
